## Lampiran D — Struktur Matriks Traceability Lengkap *(Template)*

Untuk setiap mata kuliah, matriks traceability memuat:

```
MK → CPL → CPMK → Sub-CPMK → Materi → Metode → Asesmen → Bobot
```

Contoh baris:
| MK | CPL | CPMK | Sub-CPMK | Asesmen | Bobot |
|----|-----|------|----------|---------|:-----:|
| TIN2111 | CPL03 | CPMK-2 | Sub-CPMK 2.2 | Tugas 2, Proyek | 25% |

> *Matriks lengkap untuk 65 MK dikompilasi dari seluruh RPS (BAB IX).*
