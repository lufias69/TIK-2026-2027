# BAB IX — RENCANA PEMBELAJARAN SEMESTER (RPS)

## Tentang Bagian Ini

Bagian ini memuat Rencana Pembelajaran Semester (RPS) untuk seluruh **65 mata kuliah** Program Studi S1 Teknologi Informasi. Setiap RPS disusun mengikuti **template standar** (lihat `_TEMPLATE-RPS.md`) yang sesuai dengan format SN-Dikti dan panduan OBE APTIKOM 2023.

## Struktur Folder

```
BAB-IX-RPS/
├── README.md                          ← file ini
├── _TEMPLATE-RPS.md                   ← template kosong untuk RPS baru
├── Semester-1/
│   ├── TIN1101-Logika-Informatika.md
│   ├── TIN1102-Algoritma-dan-Pemrograman.md  (contoh lengkap)
│   └── ...
├── Semester-2/
│   └── TIN2111-Sistem-Basis-Data.md   (contoh lengkap)
├── ... (Semester 3–8)
```

## Komponen Wajib Setiap RPS

Sesuai SN-Dikti Pasal 12, setiap RPS memuat:

1. Identitas mata kuliah (nama, kode, SKS, semester)
2. CPL yang dibebankan
3. CPMK dan Sub-CPMK
4. Deskripsi singkat mata kuliah
5. Bahan kajian / materi pembelajaran
6. Metode pembelajaran
7. Rencana pembelajaran mingguan (16 pertemuan)
8. Kriteria, indikator, dan bobot penilaian
9. Referensi/pustaka

## Cara Penyusunan RPS Sisa

RPS yang bertanda ⏳ disusun oleh **dosen pengampu masing-masing** menggunakan:
1. Template `_TEMPLATE-RPS.md`
2. Deskripsi MK dari BAB VII
3. Pola CPMK/Sub-CPMK dari BAB VIII
4. Rubrik asesmen dari BAB X

> *Dua contoh RPS lengkap (TIN1102 dan TIN2111) disediakan sebagai acuan kualitas dan format.*
