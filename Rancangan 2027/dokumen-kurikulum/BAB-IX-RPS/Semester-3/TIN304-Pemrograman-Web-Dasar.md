## C. DESKRIPSI SINGKAT MATA KULIAH

Mata kuliah ini membekali mahasiswa dengan konsep dasar pengembangan web. Mahasiswa mempelajari konsep client-server dan protokol HTTP, HTML, CSS responsif, JavaScript dan DOM, pemrograman sisi server, integrasi database, session & autentikasi, serta deployment aplikasi web. Kompetensi ini menjadi dasar bagi pengembangan aplikasi web statis maupun dinamis sederhana.
