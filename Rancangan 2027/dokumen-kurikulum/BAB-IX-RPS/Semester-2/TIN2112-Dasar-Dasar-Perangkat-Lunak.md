## C. DESKRIPSI SINGKAT MATA KULIAH

Mata kuliah ini membahas pengantar rekayasa perangkat lunak, mencakup SDLC (Software Development Life Cycle), requirement engineering, desain, pengujian, dan pemeliharaan perangkat lunak. Mahasiswa juga diperkenalkan pada paradigma pemrograman dan prinsip clean code yang menjadi dasar pengembangan perangkat lunak berkualitas.

---

## D. BAHAN KAJIAN / MATERI PEMBELAJARAN

- **Bahan Kajian:** BK10 (Fundamental Pemrograman dan PL)
- Konsep rekayasa perangkat lunak dan SDLC
- Paradigma pemrograman (prosedural, berorientasi objek, fungsional)
- Analisis kebutuhan (requirement engineering)
- Desain perangkat lunak (arsitektur, modul, antarmuka)
- Pengujian perangkat lunak (unit testing, integration testing)
- Pemeliharaan perangkat lunak
- Prinsip clean code dan kualitas kode

---

## E. METODE PEMBELAJARAN

| Metode | Penerapan |
|--------|-----------|
| Ceramah interaktif | Penyampaian konsep RPL, SDLC, dan paradigma pemrograman |
| Latihan terbimbing | Praktik analisis kebutuhan, desain, dan pengujian |
| Praktikum di lab | Implementasi pengujian unit dan integrasi |
| Diskusi / studi kasus | Evaluasi kualitas kode berdasarkan prinsip clean code |
