## C. DESKRIPSI SINGKAT MATA KULIAH

Mata kuliah ini membekali mahasiswa dengan keterampilan pengembangan aplikasi mobile native maupun cross-platform. Mahasiswa mempelajari konsep pengembangan mobile, UI/UX mobile, navigasi, state management, integrasi API dan backend, hingga publikasi aplikasi ke Play Store/App Store. Kompetensi ini memungkinkan mahasiswa membangun aplikasi mobile lengkap yang siap publikasi.
